# Sources and inspiration

These sources shaped the format and approach. They do not show that Bona works in any consumer product. The instructions were written for Bona; no outside skill text was copied in. Links were checked on October 29, 2026.

## Skill format and design

| Source | How it was used |
| --- | --- |
| [Agent Skills specification](https://agentskills.io/specification) | The `SKILL.md` folder layout with a name and description. A file format does not mean every chat product supports it. |
| [Anthropic on agent skills](https://www.anthropic.com/research/equipping-agents-for-the-real-world-with-agent-skills) | Load focused instructions only when needed, and judge them by actual behavior. |
| [Anthropic's skills repository](https://github.com/anthropics/skills) | Examples of focused skills. |
| [Matt Pocock's skills](https://github.com/mattpocock/skills) | Small, reusable tasks and asking questions only about unsettled decisions. Bona stops asking earlier and learns as it goes. |

## Renter guidance

| Source | How it was used |
| --- | --- |
| [FTC: rental listing scams](https://consumer.ftc.gov/articles/rental-listing-scams) | Verify who you are dealing with and where money goes. A convincing listing or tour is not proof. |
| [HUD: assistance animals](https://www.hud.gov/helping-americans/assistance-animals) | Do not apply ordinary pet rules to assistance animals by default. Check current guidance for a real case. |
